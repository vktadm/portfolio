# Python Backend разработчик

## Коротко обо мне

Специализируюсь на разработке backend-логики и API с использованием FastAPI. В рамках обеспечения бизнес-логики данными имею опыт построения вспомогательных ETL-пайплайнов. Приоритет в работе — чистая архитектура, покрытие тестами и наблюдаемость сервиса. Ищу точку приложения навыков в проектах с AI/LLM-составляющей.
## Pet-проекты

### [MemoLingo](https://github.com/vktadm/MemoLingo)

Система для изучения английских слов с системой интервального повторения FSRS. Проект реализует серверную логику для управления учебным контентом и прогрессом пользователя.
#### Стек технологий
- **Backend**: FastAPI, Python
- **База данных**: PostgreSQL
- **Кеширование**: Redis
- **ORM**: SQLAlchemy с asyncpg
- **Миграции**: Alembic
- **Аутентификация**: JWT + OAuth 2.0 Google
- **Контейнеризация**: Docker + Docker Compose
### [hhOfferBot](https://github.com/vktadm/hhOfferBot)

Сервис для автоматизированного сбора вакансий с внешних источников и предоставления доступа к ним через интерфейс Telegram бота. Включает функциональность генерации персонализированных сопроводительных писем с использованием языковых моделей.
#### Стек технологий
- Python 3.11+
- FastAPI
- Aiogram 3.x
- LangChain
- Celery
- RabbitMQ
- PostgreSQL
- SQLAlchemy / Alembic
- Docker / Docker Compose
